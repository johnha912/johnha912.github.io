CS 5800 Algorithms · Summer 2026

JOIN Order Optimization

A chain-query join-order optimizer that uses the same Θ(n³) dynamic program as matrix-chain multiplication, compared against greedy and left-to-right heuristics on four real SQLite databases (Northwind, Chinook, Sakila, F1DB). Every row count and block size is checked against the actual SQL joins. Built with teammate Yanglin “Elliot” Hu.

150.88× less intermediate work than left-to-right join order on the Sakila database
